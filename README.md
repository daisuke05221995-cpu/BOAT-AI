# BOAT AI v0.8.0

BOAT RACEの実データを取得し、予想・購入記録・結果照合・収支をまとめるAndroidアプリです。

## v0.8.0

- 会場×艇番の従来学習に加え、会場×風速帯×実進入コースを継続学習
- 風速を0〜2m / 3〜4m / 5m以上の3帯に分け、直前展示の進入コースを予想補正へ反映
- 少数データによる過学習を避けるため、同条件4件未満では追加補正を行わない
- 進入変化・強風で外れたレースの敗因表示を学習内容に合わせて改善
- 既存のv0.7以前の学習データと互換性を維持
- 風速帯・実進入コース学習の単体テストを追加

## v0.7.0

- 会場×コース結果を端末内で継続学習し、次回予想の重みへ反映
- 結果を先に見て予想へ混ぜない学習順序
- 外れたレースの敗因分析表示
- 過去日ごとの当時AI予想、的中率、仮想購入額・払戻・収支
- オッズ取得をPC版/スマホ版の二系統にして自動フォールバック
- 別チャットから再開できる `PROJECT_STATUS.md` を追加

## v0.6.1

- 通常データで欠けている締切済みレースの結果・3連単払戻を公式結果ページから補完
- 補完対象は欠落分だけ、同時取得数を制限して公式サイトへの負荷を抑制

## v0.6.0

- AI期待度を選手間の実力差・勝率差・モーター差・ST差・展示差から再計算
- 公式3連単オッズの `oddsPoint` セルを直接解析し、キャッシュを無効化
- 開催中はオッズを60秒ごとに自動更新
- 過去日と締切後のレースを購入対象から除外
- 「結果確定」「締切済み」「終了・結果取得待ち」「情報取得待ち」を区別
- 購入済みレースをチェックマークと金額付きで強調し、二重購入を防止

## v0.5.0

- 公式投票サイト風の24場開催カードUI
- 開催一覧・締切順・AI期待度順の並べ替え
- 場ごとの全レース / AI上位3レース一括選択
- 全場AI期待度80以上 / 70以上の一括選択
- AI期待度（S〜Dランク）表示
- 公式オッズ解析を固定XPath依存から全テーブル探索方式へ変更
- オッズ取得失敗理由、再取得、最終取得時刻の表示

## v0.3.0

- アプリ起動時にGitHub Releasesの最新版を自動確認
- 新版がある場合は「更新があります」を表示
- 「更新する」でAPKをアプリ内取得
- Android 8以降で必要な「この提供元のアプリを許可」画面へ誘導
- 許可後、Android標準のインストール確認画面を自動起動
- Androidの仕様上、最後の「インストール」タップだけはユーザー操作が必要
- 更新APKは毎回同じ署名鍵で作るRelease workflowを用意
- Releaseタグと`versionName`が一致しない場合は公開を停止

## 自動更新の公開先

アプリは次の公開GitHubリポジトリのLatest Releaseを確認します。

`daisuke05221995-cpu/BOAT-AI`

このリポジトリはAPK配布用に**Public**である必要があります。ソースコードのビルド元はPrivateでも構いません。

## 署名

GitHub ActionsのReleaseビルドでは以下のSecretsを使用します。

- `BOAT_AI_KEYSTORE_BASE64`: PKCS12/JKS署名鍵をBase64化した値
- `BOAT_AI_SIGNING_PASSWORD`: keystoreとalias `boatai`のパスワード

署名鍵を変えるとAndroidは既存アプリへの上書き更新を拒否するため、初回公開から同じ鍵を保持してください。
