# BOAT AI v0.18.20 自動オッズ更新 引継ぎ

## 目的

2026-10-26の実機報告「一覧ではオッズ取得待ちが続き、レースを開いた場合だけ取得される」を改善する。

## 原因と対策

1. 旧版では60秒ごとの `loadDate` が `refreshValueSelections` を再起動し、全国の公式オッズ取得処理が途中でも `valueRefreshJob?.cancel()` した。公式サイトの遅延・タイムアウト時、締切順の後半レースへ到達しにくかった。自動処理中は新規ジョブを重ねず、完了後の次周期で再開する。
2. 通常起動と通常の手動更新でも、表示される全開催分を順に120通り照会しようとしていた。通常は締切30分以内・最大4レース/パスとし、10分以内を優先、同緊急度内では未試行・最終試行の古いレースを先にする。全国一括購入推奨の明示操作は従来の全件評価のまま。
3. 画面復帰・タブ切替 `syncStoredAccounting()` と60秒更新で、当プロセスのライブ評価済み判定を履歴リストから復元し直していた。進行中の有効な判定を維持するが、最後の当プロセス評価から120秒超は `isLiveVerified` をfalseとし、再取得まではBUYを実行可能にしない。
4. 予想画面に `直前オッズ自動取得` の試行・成功・失敗件数/最後の成功時刻/失敗理由を追加。画面を開いたまま数字の更新と時刻の変化を観察できる。
5. 詳細画面の遅延HTTP結果を別レース表示へ反映しないガード、古い詳細取得のキャンセルを追加。

## テスト/検証

- `LiveRefreshPolicyTest`: 締切優先・ローテーション・最大4R。
- `AverageRoiReferenceStrategyTest`: 画面履歴同期でライブ判定を維持し、120秒後は非購入判定へ戻し、冷起動の復元は購入判断として使わない。
- 検証ブランチRun `40497497260` SUCCESS（Unit/Lint/Debug）、署名Release Run `40497909283` SUCCESS（Unit/Lint/署名APK/署名検証/公開）。

## 実機確認（公開後に必要）

1. 古いアプリを消さず上書きインストール。保存した予想・購入履歴と損益が維持されること。
2. 予想画面を5分以上開き、`直前オッズ自動取得` の試行数と成功/失敗が画面を開かず更新されること。開催・展示が揃った締切30分以内のレースが対象。
3. 締切間近の複数場で処理が1場目に固定されないこと。オッズ取得先エラーの場合も失敗数と理由が見えること。
4. 別レースへ移動しても前レースの取得結果に詳細画面を上書きされないこと。タブ移動後に新規オッズを取得できること。
5. Androidの省電力/バックグラウンド制限により前面での60秒周期は保証されない。バックグラウンドの締切5分前評価は別経路のまま。実機ログと最新のバックアップを照合する。

## 残課題

- 公式PC/スマホのオッズHTML取得先そのものの成功率は実機で未測定。API/サイトの障害時は安全側SKIPを維持。
- 360R監査済みBUY、勝率/ROIの新旧期間分離評価は新たなバックアップ取得後に実施。現行購入条件を後付けで最適化しない。
- 直近のクラッシュ詳細と欠損日の検証には、更新後に生成した匿名化バックアップが必要。
